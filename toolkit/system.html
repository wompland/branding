Three modules. One mark. Every Womp.

WompLand is a family of small publishing apps you run yourself. Its identity is a kit: a square cell, a quarter ring and a filled quarter circle, placed on a 7 × 7 field inside a 9 × 9 tile. The WompLand icon and every app icon are built from those pieces; the names beside them are set in plain Archivo.

The module kit

One module is one ninth of the tile. Every curve is exactly one module thick, so rings and stems carry the same stroke.

rot names the corner of the box that holds the circle's centre, clockwise from top-left: 0, 1, 2, 3.

      Combinations

      Stems and half circles are not modules of their own. They are cells and quarters placed side by side, and they union into one shape.

        The icon's construction

        The master icon on its construction grid. Thin seams show where one module ends and the next begins.

        Like every Womp, WompLand is marked by an icon, not a letter: a picture built from the module kit on the 7 × 7 field, with every stroke one module thick. The table counts its pieces. Nothing is drawn freehand: change a shape in the editor and this drawing changes with it.

        The lockup spec

        A lockup is the tile plus the name in Archivo 600, measured in modules of the tile (u = 1/9 of the tile).

        Names are camelCase as written (job + Womp), tracked −0.01em, and outlined in every logo file, so no file depends on the font. The tile never changes between grounds; only the name switches from ink to paper.

        One rule for every Womp

        No new design work per app. Pick the object the app is about, draw it, choose a color. The theme follows from the color.

        A Womp's glyph is the core object of its job, built from the module kit inside the 7 × 7 field, set on one palette color with that color's pale or deep partner, and followed by its name in Archivo 600.

          Making one in the editor

          1. On the Brands page, type the job word under New Womp (list makes listWomp) and create it. The editor opens with an empty field.
          2. Name the one object the app publishes or manages, and draw it with cells, quarter rings and filled quarters. Keep every stroke one module thick.
          3. Pick a palette color that no other Womp uses, then choose the pale or deep glyph, whichever reads better and stays clear of other brands' icons.
          4. Save. The editor checks the shapes and the contrast gate, then writes the logo files, icons and DaisyUI themes. The brand guide updates on its own.

          The palette rules

          Every Womp draws its tile from one curated collection, so the family stays one family.

          Edit the collection in scripts/palette.mjs; npm run palette fails on any miss.
